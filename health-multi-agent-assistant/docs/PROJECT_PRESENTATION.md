# Project presentation points

## Title
AI-Powered Multilingual Health Assistant Using Multi-Agent Architecture and Doctor-in-the-Loop

## Problem
Patients may struggle to communicate symptoms in a preferred language and doctors may need structured patient information before consultation.

## Solution
A multi-agent system collects patient information, performs triage and medical-reference retrieval, then sends a structured case to a doctor. The doctor makes the final clinical and medication decision.

## Key technologies
LangGraph, LangChain, FastAPI, React, RAG, Gemini (optional), SQLite demo database.

## Main novelty
Multilingual patient interaction + multi-agent orchestration + clinician approval workflow.
